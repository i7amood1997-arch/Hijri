# تقويم الهادي

تطبيق ويب (PWA) لتقويم هجري شيعي: مواقيت الصلاة على المذهب الجعفري، والمناسبات الدينية، وتقويم شهري كامل. يعمل بدون إنترنت بعد أول فتح.

## التشغيل
```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
node tests/test.js            # الاختبارات
```
لا يحتاج بناءً ولا مكتبات. ولتثبيته على الجوال انشره على أي استضافة HTTPS (مثل GitHub Pages) ثم «إضافة إلى الشاشة الرئيسية».

## الملفات
| الملف | الوظيفة |
|---|---|
| `js/hijri.js` | التحويل الهجري/الميلادي وضبط بداية كل شهر بالرؤية |
| `js/prayer.js` | حساب المواقيت (فجر ١٦°، مغرب ٤°، منتصف الليل الشرعي) |
| `js/events.js` | قاعدة المناسبات (أضف مناسبة بسطر واحد) |
| `js/app.js` | الواجهة |
| `sw.js` | العمل بدون إنترنت (غيّر `CACHE` عند كل تحديث) |

## ملاحظات
- بداية الشهر عند الشيعة بالرؤية: الأصل التقويم الحسابي، وتُضبط الشهور من شاشة التقويم (ضبط بداية الشهر).
- الافتراضي: المنامة، البحرين. المواقيت قورنت بمكتبة `astral` بفارق أقل من دقيقتين.
- بعض تواريخ المناسبات فيها اختلاف روايات، ونُبّه عليها في الحقل `note`.
